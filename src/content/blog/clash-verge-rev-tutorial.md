随着旧版 Clash for Windows（CFW）早已全面停止维护，开源界目前最成熟、功能最完备的现代化替代方案非 **Clash Verge Rev** 莫属。

本篇教程将手把手带您从零开始，将您在 **2027机场推荐（newjichangtuijian.blog）** 中所选购的机场订阅导入并开启加速。

---

## 一、为什么选择 Clash Verge Rev？

1. **全面支持新一代内核：** 内置 Mihomo (Clash.Meta) 内核，完美支持 Shadowsocks、Trojan、Vmess、Vless、Hysteria 2、TUIC 等全套新一代加密协议；
2. **现代美观 UI 与原生中文：** 支持深色模式，界面整洁清爽；
3. **强大的 TUN 模式：** 虚拟网卡接管系统全部流量，彻底解决部分软件（如 Git、命令行终端、UWP 应用、游戏客户端）不走系统代理的问题。

---

## 二、Clash Verge Rev 下载与安装

请务必前往官方 GitHub 开源发布页或正规镜像源下载安装包：

- Windows 用户：下载 `.exe` 安装程序（通常为 `Clash.Verge_x64-setup.exe`）
- macOS 用户：Intel 芯片选择 `x64.dmg`，Apple Silicon (M1/M2/M3/M4) 选择 `aarch64.dmg`

> 提示：初次安装运行时若遇到 Windows SmartScreen 提示，点击“更多信息”并选择“仍要运行”即可。

---

## 三、导入 2027 机场推荐订阅步骤

1. **登录您的机场用户中心：** 复制您的专属订阅链接（或点击“一键导入 Clash”）；
2. **打开 Clash Verge Rev：** 点击左侧菜单栏的 **「订阅 (Profiles)」**；
3. **粘贴订阅地址：** 在顶部输入框中粘贴您的订阅 URL，点击右侧的 **「导入 (Import)」** 按钮；
4. **选中该订阅：** 导入成功后，列表会显示该订阅卡片，鼠标左键点击将其激活（卡片左侧会出现高亮选中标识）。

---

## 四、选择节点与开启系统代理

1. 点击左侧导航栏的 **「代理 (Proxies)」**，进入节点选择面板；
2. 推荐选择 **「规则 (Rule)」** 模式（国内网站直连、海外网站自动分流翻墙）；
3. 在策略组中选择您想连接的节点地区（如香港、日本、美国、新加坡）；
4. 点击左侧 **「设置 (Settings)」**，打开 **「系统代理 (System Proxy)」** 开关。

此时打开浏览器访问海外网站，即可畅享秒开体验！
