## 二、各操作系统最佳推荐组合

### 1. Windows 用户首选：Clash Verge Rev
- **适合人群：** 追求界面美观、平时玩外服游戏、需要让终端或 Git 走代理的用户。
- **最大亮点：** 一键开启 **TUN 模式**，系统级别虚拟网卡直接接管所有流量，无需手动给单个软件配置 `http_proxy`。
- **推荐搭配机场：** [隐形人](https://varnexa.invisibleaff.com/#/?code=JF4seZUy) / [暮光加速](https://varnexa.twilightaff.com/#/?code=3qqonTlH) / [微风网络](https://edp01.breezenetaff.com/#/?code=4KDOroY0)。

### 2. macOS 苹果电脑首选：Clash Verge Rev (ARM64版)
- **适合人群：** M1/M2/M3/M4 芯片的 MacBook 及 Mac mini 用户。
- **最大亮点：** 针对 Apple Silicon 原生编译，CPU 占用率低于 0.5%，完全不影响电池续航。

### 3. iPhone / iPad 苹果移动端首选：Shadowrocket（小火箭）
- **获取方式：** 登录海外（如美区、日区、港区）Apple ID 在 App Store 购买下载（售价约 $2.99）。
- **最大亮点：** 功能极其强大，不仅能一键导入各大 2027 机场的订阅链接，还内置测速、分流规则定制、家庭自动化等实用功能。

### 4. Android 安卓手机首选：Clash Meta for Android 或 Sing-box
- **适合人群：** 华为、小米、OPPO、vivo 及三星等安卓手机用户。
- **最大亮点：** 后台保活能力强，支持分应用代理（可排除银行、微信、支付宝等国内应用，既省流量又避免风控）。

## 三、常见配置疑难解答

1. **导入订阅提示“网络超时”或“连接失败”怎么办？**
   - 检查订阅链接前后是否有空格；
   - 若本地开启了旧代理软件，请先退出旧软件并重置系统代理设置；
   - 尝试在浏览器中直接打开该订阅链接，确认机场后端服务是否正常。
2. **为什么开启代理后国内某些网站（如微信、百度）变得很慢？**
   - 确认代理模式是否处于 **「规则 (Rule)」** 模式，切勿误点成「全局 (Global)」模式。在规则模式下，国内网站直连不消耗翻墙流量与专线带宽。
